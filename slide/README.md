# Workspace INIXINDO Picture Slides
Salin folder ini ke folder kerja baru (struktur `build/`, `ref/`, `work/` harus tetap), lalu:

    cd build && python3 build.py deck.pptx

- `ref/ref.pptx` : templat INIXINDO (dibaca saja)
- `build/footer.svg` : footer resmi INIXINDO Bandung
- `build/c1.py` : kerangka awal berisi contoh tiap jenis slide; ganti dengan isi topik Anda
- `build/viz/specs/contoh.py` : contoh spesifikasi ilustrasi
Dokumentasi: ../references/*.md dan ../SKILL.md
